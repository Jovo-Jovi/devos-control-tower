### Notes for the reviewer
- **403.** `forbidden()` (`experimental.authInterrupts`, Next 16.4 docs `forbidden.md`) is how a page sets HTTP 403. It is called from `src/app/sign-in/page.tsx` when `reason=not_owner`, before streaming. The denied card is `SignInCard` from `src/app/sign-in/forbidden.tsx`, because `forbidden()` replaces the segment's return value. A direct request returns 403 and the denied sentence is in the body. Next renders that status in `<html id="__next_error__">` without `lang` or `dir` (`app-render.js` error shell). `DocumentLocale` sets both from `defaultLocale` after hydration. `/sign-in` itself is 200 with `lang="en" dir="ltr"` in the document.

The nonce is on `script-src` only: a style nonce would make the browser ignore `'unsafe-inline'` (CSP3). Kept because Next emits inline styles for `next/font`.
