- **S1 — Migration `20261026090000_link_requests.sql`.** Fully qualified names, `pg_catalog.` for built-ins.
  - `public.link_requests`: exactly `DATA_MODEL.md` §2.10. That is every column, default, `check` (with the patterns
    verbatim), the foreign key `project_id … references public.projects (id) on delete set null`, `unique
    (repository, owner_github_id)`, and the three table checks.
  - `public.link_audit`: exactly §2.11.
  - `alter table … enable row level security` on both. Policies: `link_requests_owner_select` and
    `link_audit_owner_select`, each `for select to authenticated using (public.is_owner())`. Write no other policy.
  - Grants: `revoke all on public.link_requests, public.link_audit from anon, authenticated;` then
    `grant select on public.link_requests, public.link_audit to authenticated;`. Do not revoke anything from
    `service_role`: it keeps Supabase's default privileges, which the functions below use.
  - Three functions, each `language plpgsql`, `security invoker`, `set search_path = ''`, then
    `revoke all on function … from public, anon, authenticated;` and
    `grant execute on function … to service_role;`
    1. `public.request_link(p_repository text, p_owner_github_id text, p_proposed_key text, p_engine_version text,
       p_contract_version text) returns jsonb`:
       - First, raise with `errcode = '22023'` if any argument is null or fails its §2.10 pattern.
       - Lock the row for `(p_repository, p_owner_github_id)` (`for update`). If it exists, set
         `last_requested_at = pg_catalog.now()`, `engine_version` and `contract_version` from the arguments. Keep
         `proposed_key`.
       - Then, in this order:
         - state `declined` → `{"result":"declined"}`;
         - state `approved` → `{"result":"linked","key":<the key of the project with id = project_id>}`;
         - otherwise, a `public.projects` row with `repo = p_repository` and `owner_github_id = p_owner_github_id` →
           `linked` with its key;
         - a pending row → `{"result":"pending"}`;
         - no row and `count(*)` of pending rows ≥ 50 → `{"result":"rate_limited"}`, and nothing is written;
         - no row → `insert … on conflict (repository, owner_github_id) do nothing returning id`. If a row was
           inserted, insert `link_audit (action, request_id)` = `('requested', <id>)`. Return `pending`.
    2. `public.approve_link_request(p_request uuid) returns jsonb`:
       - Lock the request. None → `{"result":"not_found"}`. State not `pending` → `{"result":"not_pending"}`.
       - A project with `repo = repository`:
         - with the same `owner_github_id`: take that project;
         - with another owner id: `{"result":"repo_taken"}`, and nothing changes.
       - Otherwise insert a project (`key`, `repo`, `owner_github_id`; default stale window). The key is the first
         one no project has: `proposed_key`, then for n = 2, 3, … the value
         `pg_catalog.left(proposed_key, 32 - pg_catalog.length('-' || n)) || '-' || n`.
       - Set `state = 'approved'`, `decided_at = now()` and `project_id`. Insert audit `approved`. Return
         `{"result":"approved","key":<key>}`.
    3. `public.decline_link_request(p_request uuid) returns jsonb`:
       - None → `not_found`. Already `declined` → `not_pending`.
       - Otherwise set `state = 'declined'` and `decided_at = now()`, and keep `project_id` (a disconnected project
         when it is set). Insert audit `declined`. Return `{"result":"declined"}`.
  - Write no `security definer` function. Grant nothing to `anon`.
