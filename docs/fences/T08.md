- **S1 — `scripts/devos/screens.mjs`: module plus main.** Move the run into `async function main()`, called only when
  the file is executed (`process.argv[1]?.endsWith("screens.mjs")`, as `builder-model.mjs:77`). Importing the module

  `DEVOS_CHROMIUM`, the bypass headers, `next start` with `readEnvFile()`, the "skipped" exits. Add `--task Tnn`
  (default `process.env.TASK`). Export exactly these:
  - `parseScreensLine(fenceText)` → `{ found, states, errors }`. Reads the first line matching `^- Screens:` before
    `### Prompt`. Entries are the backticked texts on that line, separated by ` · `. Each entry is
    `<name> <path>[ <action> <selector>]`: name `^[a-z0-9][a-z0-9-]*$`, path starts `/` (query allowed), action
    `click|hover|focus`, selector = the rest, trimmed and non-empty. A state is `{ name, path, action }`, where action is
    `null` or `{ type, selector }`. A bad name, a bad path, an unknown action or a duplicate name adds one string to
    `errors` and drops that entry.
  - `pickFrames(frames, t0, targets)` → one `{ target_ms, frame_ms, index }` per target. `frames` are
    `{ ts }` in epoch ms, ascending. Target 0 takes the first frame with `ts ≥ t0`. A target t > 0 takes the latest
    frame with `ts ≤ t0 + t`, never earlier than target 0's frame. `frame_ms = ts − t0`, rounded. With no frame:
    `index -1`, `frame_ms null`.
  - `captureStates({ browser, url, states, widths, outDir, filmstripMs, settleMaxMs, headers })` → captures (below).
  - `motionSummary(manifest)` → Markdown lines. `motionCounts(manifest)` →
    `{ states, widths, captures, settled, reduced, frames, shifted, errors }`.
- **S2 — State source, in order:** page arguments (`states_from` `command line`) → `parseScreensLine` of

  (`devos.config.json screens.pages`). A page-only state has `action null` and the name derived as today

- **S3 — One capture per state × width** (`WIDTHS` 1280×900 and 390×844, unchanged), in a new page per capture:
  1. **Normal motion**, context `reducedMotion: "no-preference"`. An init script sums the `value` of `layout-shift`
     entries without `hadRecentInput` (`PerformanceObserver`, `buffered: true`). Start a CDP screencast
     (`newCDPSession`, `Page.startScreencast` PNG, `everyNthFrame: 1`, the viewport size) and ack every frame
     (`Page.screencastFrameAck`). Use `metadata.timestamp × 1000` (`clock: "frame"`), or else the receive time
     (`clock: "receipt"`). The **trigger** of a page-only state is first contentful paint:
     `performance.timeOrigin` + the `first-contentful-paint` entry, else `first-paint`, polled up to 10 s after
     `goto(..., { waitUntil: "commit" })`. For an action state: settle first, then the trigger is
     `performance.timeOrigin + performance.now()`, read just before the action. Record until trigger +
     max(`filmstripMs`) + 100 ms, stop the screencast, then write the `pickFrames` frames as
     `<name>-<width>-film-NNN.png` (NNN = target, three digits).
  2. **Settle**: network idle, `document.fonts.ready`, then poll until no animation with finite iterations is running
     (`document.getAnimations()`), capped at `settleMaxMs` (`settle_capped`). Write the full-page
     `<name>-<width>.png` and read the layout-shift sum.
  3. **Reduced motion**, context `reducedMotion: "reduce"`: the same goto, settle and action, then the full-page
     `<name>-<width>-reduced.png` and its own layout-shift sum.
  4. In both contexts, record `matchMedia("(prefers-reduced-motion: reduce)").matches`.
  A capture that throws keeps its `error` (message) and the run continues.
