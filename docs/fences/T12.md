### Prompt (canonical)

Make the planet sharp at any size and screen density. Today each globe is a CSS strip warped by an 8-bit
`feDisplacementMap` from a 340×340 map, so near the centre neighbouring pixels copy one texel and the clouds become
small squares. Replace the filter by a canvas per globe that samples the strip **per device pixel** on a sphere, with
WebGL 1 and no library. Everything else stays: the slot, size, position, glows, the crimson mask disc and its roll,
shade, atmosphere, the 120 s spin and the half turn on the switch, all from the unchanged tokens and CSS.

- **Timing stays CSS.** The `.spin` and `.turn` wrappers keep their animation and transition. The renderer reads
  their computed `translateX` every frame and turns it into the sphere's longitude, so reduced motion (the global
  `animation: none; transition: none`), the hidden pause (`:root[data-scene-paused]`) and the evidence tests'
  `pause()`/`currentTime` act on the canvas exactly as on the CSS today.
- **Still globe** when `prefers-reduced-motion: reduce` holds (WebGL draws on change only) and when WebGL is not
  available (a 2D canvas drawing, on change only). Until a canvas has drawn, or when no context exists, the flat strip
  inside `.turn` stays visible as the poster.
- **Loading stays `DESIGN_SYSTEM.md` §9.** The strips keep loading from the CSS rules (the theme's strip before the
  first paint, both after `:root[data-scene-ready]`). The renderer takes the URL from its strip's computed
  `background-image`, so it never requests a second URL. The page never waits for an image.
- **Rules that hold:** logical properties only; no colour, px, duration or easing in CSS outside `tokens.css` (1px
  hairlines allowed); no `style` prop and no `.style` write in `src/`; only `transform`, `opacity`, `clip-path`,
  `stroke-dashoffset`, `offset-distance` and `mask-position` animate; nothing stored in the browser; no new host or
  dependency; no route, header, CSP, token or data change.

- **S2 — `src/components/scene/sphere.ts`** (pure, no DOM), exporting exactly these four functions:
  - `translateX(transform: string): number` — `"none"` → `0`; `matrix(a, b, c, d, e, f)` → `e`;
    `matrix3d(…16 values…)` → the 13th value; anything else → `NaN`.
  - `centreU(spinX: number, turnX: number, tile: number): number` — the texture coordinate at the globe's centre,
    `(tile / 4 − spinX − turnX) / tile` wrapped into `[0, 1)`. (Today's flat strip shows half of a `tile`-wide tile:
    at `translateX(t)` its window spans `[−t, −t + tile/2]`, centre `−t + tile/4`.)
  - `sampleSphere(x: number, y: number, centre: number): { u: number; v: number } | null` — orthographic sphere;
    `x` grows toward the right edge, `y` downward, both in `[−1, 1]`; `null` when `x² + y² > 1`; else with
    `z = √(1 − x² − y²)`: `u = centre + atan2(x, z) / (2π)` wrapped into `[0, 1)`, `v = 0.5 + asin(y) / π`.
  - `backingSize(cssSize: number, ratio: number): number` — `Math.max(1, Math.round(cssSize × ratio))`.
- **S3 — `src/components/scene/sphere.test.ts`** (vitest), at least these cases, each its own `it`:

  → 0.5; `sampleSphere(-1, 0, 0.25).u` → 0; `sampleSphere(0, -1, 0).v` → 0; `sampleSphere(0, 1, 0).v` → 1;

- **S5 — `src/components/scene/PlanetGlobe.tsx`, the WebGL path.** `"use client"`,
  `export function PlanetGlobe({ side }: { side: "day" | "crimson" })`, rendering only
  `<canvas ref={…} className={styles.canvas} data-planet-canvas={side} aria-hidden="true" />` (`styles` from
  `./Planet.module.css`). One `useEffect` does all the work; no React state. It finds its elements with
  `canvas.parentElement.querySelector(…)`: `[data-planet-spin]`, `[data-planet-turn]` and `[data-planet-strip]` (all
  inside the `.spin` sibling).
  1. **Image.** Read `getComputedStyle(strip).backgroundImage`; take the URL inside `url("…")`. If it is `none`, wait
     for `data-scene-ready` on `<html>` (a `MutationObserver`), then read it again. Load it with `new Image()` and
     `await image.decode()`; never insert an element into the DOM.
  2. **Context.** `canvas.getContext("webgl", { alpha: false, antialias: false })`; if it is `null`, set
     `data-planet-renderer="none"` and stop (the poster stays; Stage 2 adds the 2D path). Otherwise set
     `data-planet-renderer="webgl"`.
  3. **Size.** Before every draw: `const rect = canvas.getBoundingClientRect()`, and `canvas.width =
     canvas.height = backingSize(rect.width, window.devicePixelRatio || 1)` when they differ. No cap on the ratio.
  4. **Longitude.** `tile = parseFloat(getComputedStyle(canvas).getPropertyValue("--planet-tile-inline"))`;
     `turnX = translateX(getComputedStyle(turn).transform)`; `spinX = translateX(getComputedStyle(spin).transform)`
     (under reduced motion the CSS gives `none`, so 0); `centre = centreU(spinX, turnX, tile)`.
  5. **Draw.** One full-canvas quad (two triangles). The fragment shader starts with
     `#ifdef GL_FRAGMENT_PRECISION_HIGH` / `precision highp float;` / `#else` / `precision mediump float;` / `#endif`
     (at `mediump` a 2048-texel strip resolves to about two texels on some phone GPUs, which would bring the squares
     back). It maps `gl_FragCoord` to `x, y` in `[−1, 1]` (`y` downward), moves `(x, y)` onto the unit circle when
     outside it (the `.disc` CSS clips the corners), and samples at `u = centre + atan(x, z) / (2π)` (no wrap in the
     shader: the texture repeats) and `v = 0.5 + asin(y) / π`, the same formulas as `sampleSphere`. The texture is
     uploaded once, without `UNPACK_FLIP_Y_WEBGL` (row 0 = the strip's top, so `v` is used as is), with
     `generateMipmap`, `TEXTURE_MIN_FILTER` `LINEAR_MIPMAP_LINEAR`, `TEXTURE_MAG_FILTER` `LINEAR`, `TEXTURE_WRAP_S`
     `REPEAT` and `TEXTURE_WRAP_T` `CLAMP_TO_EDGE` (2048×1024 is a power of two, so WebGL 1 allows all three).
     `gl.viewport(0, 0, canvas.width, canvas.height)` on each draw. After the first draw set `data-planet-drawn`.
  6. **Running or still.** The globe **runs** (a `requestAnimationFrame` loop drawing every frame, with
     `data-planet-running` set on the canvas) only when the renderer is `webgl`, `(prefers-reduced-motion: reduce)`
     does not match, `document.visibilityState` is not `hidden` and `<html>` has no `data-scene-paused`. Otherwise it
     is **still**: no loop, no `data-planet-running`, one draw on each change. Changes that re-evaluate this: image
     ready; `data-theme`, `data-scene-paused` or `data-scene-ready` on `<html>` (one `MutationObserver`);
     `visibilitychange`; the reduced-motion and `(prefers-color-scheme: dark)` queries' `change`; window `resize`; and
     `transitionend` on the turn element (so a still globe lands on its theme's position after a switch).
  7. **Cleanup** on unmount: cancel the frame, disconnect observers, remove listeners, and
     `getExtension("WEBGL_lose_context")?.loseContext()`.
  No colour literal, no `style` prop and no `.style` write in the file; no number in it is a duration.
