"Check out the task branch (a reissue continues the same branch, PR-03)" with `docs/fences/T16.md does not exist: the
reviewer has not issued this fence` (`devos-cycle.yml:215`). The supervisor then re-ran the run twice as "an

cause, keep a request open until every task its plan names is PASS, and keep runner comments out of the owner's
notes. Keep every existing supervisor rule, key and action as it is: the self-test pins them.
