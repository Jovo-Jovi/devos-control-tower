### Prompt (canonical)

The panel lists every decided request in full, so it grows with every link. OD-14 §5 keeps **Pending** open and
unchanged, and collapses **Linked by request** and **Declined**. Each starts as a button with its title and count. Opened,
it shows one line per request, and a line opens that request's details and actions in place. The task also lands the
T20 review's five carry-forwards and fixes one of them, CF-040 (the disabled "Delete for good" looks enabled).

Rules that hold throughout:
- **Pending** keeps today's markup and behaviour exactly. Server actions, `groups.ts`, the catalogue and the data do not
  change. No catalogue key is added: `guard:i18n` stays at 214.
- The open state lives in React state only. Nothing is stored in a cookie, browser storage, a URL parameter or the
  database. Every page load starts collapsed.
- Native `<button type="button">` elements, `aria-expanded` and `aria-controls`. The controlled element is always in the
  DOM: while collapsed it carries `hidden` and has no children. Opening or closing never remounts the button, so focus
  stays on it.
- **Design.** No colour, px (except `1px` hairlines), duration or easing outside `tokens.css`, which does not change. Use
  logical properties only, no `style` prop and no literal UI text in TSX. Only `transform` and `opacity` animate.
  Repositories and keys go in `Bidi`. The focus ring follows `DESIGN_SYSTEM.md` §6, as `.action:focus-visible` does.
- **No** route, dependency, header, CSP, data or `playwright.config.ts` change. Fixtures are synthetic.
