1. **The bar SVG fills its track in both directions** (S4 `Bar`; DESIGN_SYSTEM §5.2; mockup `.fill{height:100%}`).
   - The cause: `.meter` (`Bar.module.css:27–30`) is `position: absolute; inset: 0` alone. The `<svg viewBox="0 0 100 1">`
     is a replaced element, so `inset: 0` gives it the track's width, but its height follows the 100:1 ratio
     (track width / 100). It sits at the top of the 4 px (`--space-1`) track, and the stroke fills only that strip.
   - Required in `src/components/Bar.module.css`: `.meter` keeps `position: absolute;` and `inset: 0;`, and adds
     `inline-size: 100%;` and `block-size: 100%;` in the same rule, so the rule holds all four declarations. On an
     absolutely placed element the two sizes resolve against `.track` (`position: relative`), so the SVG fills the
     track and still adds no intrinsic size.
   - Nothing else in `Bar.module.css` changes, and `Bar.tsx` does not change.
