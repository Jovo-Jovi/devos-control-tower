design v3 everywhere, without changing what any page does:

There is no data work and no route or header change. The project cards, `/api/projects`, `/projects/new` and the
banner are T05. The sign-in states are T09.

Rules for the whole task:
- **Nothing is stored** (OD-08 §3). The switch sets or removes `data-theme` on `<html>`. It uses no cookie, no
  browser storage and no URL parameter, and a reload returns to Auto.
- **Production CSP** (`src/proxy.ts`): `style-src 'self' 'nonce-…'` blocks inline `style` attributes. Server markup
  carries no `style` attribute or prop, including in SVG. Position SVG shapes with their attributes (`cx`, `cy`,
  `x`, `y`, `d`, `opacity`). Colour them with CSS classes that read §1 tokens.
- **Images** come only from `src/components/scene/assets/`, bundled and served under `/_next/static/media/`
  (`DESIGN_SYSTEM.md` §9, OD-08 §7). There is no `public/` directory.
- **Motion** follows `DESIGN_SYSTEM.md` §5. Durations, easings, distances and every raw value come from
  `tokens.css`. Only the listed properties animate. Every loop stops under `prefers-reduced-motion: reduce` and
  while the document is hidden.
