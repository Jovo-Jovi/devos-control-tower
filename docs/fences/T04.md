- **S2 — Data.**
  - `src/lib/portfolio/aggregate.ts` is pure, with no I/O. It exports these types:
    - `PortfolioProject` = `{ key: string; repo: string; staleAfterMinutes: number; lastActivityAt: string | null;
      lastContactAt: string | null; latest: { step: string; status: string; origin: string; receivedAt: string } |
      null; freshness: "fresh" | "stale" | "none" }`
    - `PortfolioTotals` = `{ projects; tasksPassed; tasksTotal; measuredAttempts }` (numbers)
    - `Portfolio` = `{ projects: PortfolioProject[]; totals: PortfolioTotals; generatedAt: string }`
  - `aggregatePortfolio(projectRows, stepEventRows, measuredEventIds, now: Date): Portfolio`. Per project:
    - `lastActivityAt` = max `at`; `lastContactAt` = max `received_at` (GLOSSARY §2: two values, never merged).
    - `latest` = the event with the greatest `received_at`, a tie going to the greatest `id`.
    - `freshness` = `none` without events, `stale` when `now − lastContactAt` exceeds `staleAfterMinutes` minutes,
      else `fresh`.
    - Sort: projects with contact first, by `lastContactAt` descending, then the rest by `key`.
  - Totals:
    - `projects` = the count of projects.
    - `tasksTotal` = distinct `(project, task)` over events whose `task` is not null.
    - `tasksPassed` = those pairs that have an event with `step = 'verdict'` and `status = 'pass'`.
    - `measuredAttempts` = distinct `event_id` of `event_usage` rows with `source = 'measured'`.
  - `src/lib/supabase/server/portfolio.ts` (`import "server-only"`) exports `loadPortfolio(): Promise<Portfolio |
    "unavailable">`. It reads through `createSessionClient()` only:
    - `projects (id, key, repo, stale_after_minutes)`;
    - `events (id, project_id, task, step, status, origin, at, received_at)`;
    - `event_usage (event_id)` where `source = 'measured'`.

    Every read is paged with `.range()`, 1 000 rows a page, until a short page; there is never a single capped read.
    Any error → `"unavailable"`.
  - `requireOwner()` in `session.ts` also returns `githubId: string`: the `id` of the `github` entry in
    `user.identities` (`auth.identities.provider_id`, never metadata). Nothing else in that file changes.
